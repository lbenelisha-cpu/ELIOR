עדכון ביצוע עסקאות Binance Demo Spot

העדכון טרם הופעל בחשבון. הוא מתחיל לשלוח פקודות דמו רק אחרי ההגדרה המתוארת להלן.

1. חלץ את ZIP והעלה את הקבצים ל-GitHub ELlOR במקום הקבצים הקיימים. שמור את תיקיית lib. אין להעלות את ZIP עצמו.
2. המתן לפריסת הקוד ב-Render וב-Netlify.
3. Binance Demo > API Management: השתמש במפתח System generated של חשבון Demo Spot עם הרשאות קריאת חשבון ומסחר Spot. אין לשלוח מפתחות בצ'אט או להכניס אותם לקבצי GitHub.
4. Render > שירות binance-wave-agent > Disks: ודא שקיים Persistent Disk עם Mount Path /var/data. אם אינו קיים, הוסף אותו לפני הפעלת המסחר. Render מאפשר דיסק קבוע בשירות בתשלום. אין להפעיל מספר מופעים או שירות נוסף על אותו חשבון.
5. Render > Environment:
BINANCE_DEMO_API_KEY = מפתח הדמו שכבר הוגדר
BINANCE_DEMO_API_SECRET = סוד הדמו שכבר הוגדר
BINANCE_DEMO_STATE_FILE = /var/data/binance-demo-trading.json
BINANCE_DEMO_TRADING_ENABLED = true
BINANCE_LIVE_TRADING_ENABLED = false
AUTO_EXECUTION = false
6. לחץ Save, rebuild, and deploy. כשהשירות Live, רענן את האתר Ctrl+F5 ובחר DEMO.
7. הכותרת צריכה להציג BINANCE DEMO · מסחר אוטומטי, והסכומים USDT. בדוק ביומן פעולות וגם ב-Binance Demo > Order History. הסוכן מחכה לאות קנייה; הפעלת החיבור אינה מבטיחה קנייה מידית.

אופן הפעולה:
- סריקה כל 5 דקות, קנייה ומכירה לפי אסטרטגיית הסוכן הקיימת. עד 3 פוזיציות.
- ההון המנוהל הוא USDT, USDC ופוזיציות שהסוכן פתח בדמו. יתרות אחרות שהוכנסו ידנית מוצגות בכרטיס כלל החשבון אך אינן נמכרות אוטומטית.
- יעד כל פוזיציה: שליש מהשווי המעודכן. ההקצאה לקנייה מוגבלת למזומן הזמין ומותירה 0.2% מרווח לעמלות ועיגול. אין איזון כפוי של עסקאות פתוחות רק כדי להשוות את שוויין.
- רווח ממומש נוסף למזומן ומשתתף בקניות הבאות. שווי פתוח משפיע על היעד אך אינו יוצר מזומן.
- אם צריך USDT למימון הקניות, הסוכן מוכר USDC בדמו בצמד USDCUSDT. אם הצמד אינו זמין תוצג שגיאה והקנייה לא תישלח.
- הפוזיציות הישנות של סימולציית 5000 ש״ח אינן מועברות לחשבון Binance.
- פקודה עם תשובה לא ודאית נשמרת ונבדקת לפי מזהה לפני המשך. אם Binance לא מאפשר לברר אותה, המסחר מושהה. אין למחוק קובץ מצב, להחליף חשבון או לשחזר דיסק בלי בדיקת הפקודות ב-Binance.
- עצירה: BINANCE_DEMO_TRADING_ENABLED=false ופריסה מחדש. פוזיציות Binance קיימות נשארות פתוחות ולא יימכרו מעצמן לאחר העצירה.

בדיקות:
13 בדיקות ממוקדות עברו, כולל חלוקה שווה, מימוש רווח, המרת USDC, מניעת כפילות ושחזור אחרי ניתוק. הן משתמשות בשרת מדומה; לא בוצעה פקודה בחשבון המשתמש.
הרצת npm test הרחבה: 50 עברו, 5 נכשלו בקוד שלא השתנה: 4 עקב תלויות חסרות בסביבה המקומית, ואחת בציפיית UI ישנה. בדיקות תחביר הקבצים שעודכנו עברו.
