# חיבור LEVI ל־MT5

החיבור מציג את החשבון הפעיל ופוזיציות פתוחות במחשב שבו MT5 פועל. הוא אינו שולח הוראות מסחר. אין להדביק את מפתח MT5 בשדה מפתח הצפייה של MT4 באתר.

1. התחבר לחשבון ב־MT5. פתח Ctrl+O, לשונית MCP, שמור את ההגדרות ולחץ Copy.
2. הפעל את `mt5/Start-MT5.ps1` ב־PowerShell. אם אין Node.js מותקן, התקן מהאתר הרשמי nodejs.org. בעת הבקשה העתק שוב את הגדרות MT5 והקש Enter.
3. השאר את החלון פועל ופתח http://127.0.0.1:22347/mt5.html בדפדפן במחשב הזה.
4. סגירת חלון השירות מנתקת את התצוגה. מפתח MT5 מוחזק בזיכרון התהליך בלבד ולא נשלח ל־Netlify.

עמוד `mt5.html` באתר מספק קישור לתצוגה המקומית. התצוגה פועלת גם אם האתר טרם עודכן. כדי להוסיף את הקישור לאתר, העלה את הקבצים החדשים ואת השינוי ב־index.html למאגר המקורי ופרוס ב־Netlify.

כאשר MT5 מדווח שהוא מנותק מהברוקר, מוצג החשבון המוגדר אך יתרה ופוזיציות אינם מוצגים כנתונים עדכניים. השירות מאזין רק ב־127.0.0.1 ובודק מקור בקשה ומפתח הפעלה מקומי. אין לחשוף את הפורט לרשת או להעלות מפתחות למאגר.

החיבור אינו משנה את סוכני MT4/דמו הקיימים. הפעלת מסחר אוטומטי בלייב דורשת התאמה נפרדת של אסטרטגיות, פקודות וניהול סיכונים.
